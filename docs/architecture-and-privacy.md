# 구조와 개인정보 점검

nyatinorma는 npm 의존성인 `@earendil-works/pi-coding-agent`와 `@earendil-works/pi-ai` 0.87.1을 사용한다. pi 소스나 설치 패키지를 수정하지 않는다. 실행기는 pi CLI에 `extensions/nyatinorma.ts`를 로드한다. 별도 pi 포크가 아니며, 현재는 독립 실행기와 확장을 함께 제공하는 프로젝트다.

TUI, 입력 이력, 대화 트리/분기/재개, 도구 루프는 pi를 재사용한다. 창 캡처·클릭·드래그, 진행/지식 저장, 후보 선택은 확장이 제공한다. Ollama 네이티브 `/api/chat`은 별도 어댑터다. OpenAI 호환 서버 등은 pi 기본 provider를 사용하며 `.nyatinorma/pi/models.json`과 `/model`로 등록·선택한다. SELECT의 확률 해석만 추가 구현이며 OpenAI 호환 요청 자체는 pi의 스트리밍·인증·호환 설정을 재사용한다.

모델 ID, 서버 주소, 모델 컨텍스트/출력 한도와 추론 지원은 로컬 설정으로 지정한다. 특정 모델명은 소스에 고정하지 않는다. 모델은 이미지와 도구 호출을 지원해야 하며 SELECT에는 logprobs가 필요하다. 서버가 선택 점수를 제공하지 않으면 이를 만들어 내지 않고 THINK로 반환한다. 모든 Ollama 모델의 호환성을 시험한 것은 아니다. Ollama 기본 등록값은 `nyatinorma.json`, 그 밖의 provider 등록은 pi 표준 models.json을 사용한다. 시작 모델을 강제하지 않는다. `.nyatinorma/pi/models.json`은 덮어쓰지 않는다. 서버의 모델 등록·상주 설정은 건드리지 않는다.

## 배포 경계

- `nyatinorma.json`은 로컬 설정이다. Git 제외와 npm files 허용 목록으로 배포에서 제외한다. 일반 예제는 `nyatinorma.example.json`이다.
- `.nyatinorma/`에는 대화, 창 캡처, 지식, 실행 이력과 pi 설정이 있으므로 개인 데이터로 취급한다. Git/npm 배포 대상이 아니다.
- `.env*`, 로컬 인증 파일, 빌드된 브리지 앱도 제외한다. 스킬 폴더를 별도로 공유하면 스크린샷·관측 메모가 포함될 수 있다.
- 공개 전 Git에 추가한 파일을 대상으로 개인 홈 경로, 사설 IP, URL 내 자격 증명, 알려진 인증키/개인키 패턴과 파일 구성을 검사한다. 예제의 localhost 주소, 테스트용 더미 인증값, 저작권·라이선스 표기는 유지한다. 패턴 검사는 모든 종류의 개인정보 부재를 보증하지 않는다. 디렉터리 전체를 수동 압축하면 Git 제외 규칙은 적용되지 않는다.

## 검증

검증 명령은 `npm run typecheck`와 `npm test`다. 실제 pi RPC를 모의 Ollama와 연결해 빈 시작, 자동 저장, 이름 변경, 새 대화/분기/재개, 모델 도구를 통한 지식/프리셋 생성과 범용 체크포인트 저장을 검증했다. 입력 드라이버 테스트는 공유 서비스 변경 금지, 취소, 창/좌표 검사와 드래그 분리를 확인한다. 실제 모델의 장기 자율 작업 성공률과 Windows 게임 입력은 아직 검증하지 않았다.
