# Publication and distribution plan

Target repository: https://github.com/nyabia/nyatinorma

Prepared: original-code MIT OR Apache-2.0 licensing, third-party reference notices,
lockfile license inventory, local-data exclusions and generic configuration example.

This publication contains source, tests, documentation and license notices only.
Dependencies, native binaries, local configuration and runtime data are excluded.

Planned next work, not implemented:

- A project homepage explaining the pi extension architecture and experimental support scope.
- Convenient macOS/Linux and Windows installers, comparable in usability to oh-my-pi.
- Versioned releases and an explicit update command, with configuration/data preserved.
- Integrity verification and release-specific third-party/native-library notices.
- Fresh-machine installation checks and platform-specific permission instructions.

A standalone Bun executable is an option to evaluate, not a completed artifact.
The current launcher still uses Node/npm and installed pi dependencies. Source checkout instructions are in README.md.
